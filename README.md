# 🌿 Kurdistan Eco Power (سیستەمی ئیکۆ)

ئەم پڕۆژەیە ئامرازێکی سەربەخۆ و "Open Source"ە بۆ هاوکاری هاوڵاتیانی هەرێمی کوردستان، بەتایبەت بۆ چاودێریکردن و هەژمارکردنی تێچووی کارەبا بەپێی سیستەمی نوێی "پێوەری زیرەک".

## 🎯 ئامانجی پڕۆژە
زۆربەی هاوڵاتیان متمانەی تەواویان بە شێوازی هەژمارکردنی پارەی کارەبا نییە. ئەم وێبسایتە ڕێگەیان دەدات:
- **هەژمارکردنی ورد:** بزانن یەکەکانیان چۆن دابەش دەبێت بەسەر ئاستەکاندا (Slabs).
- **پێشبینیکردنی بودجە:** بەر لەوەی پسوولەکەیان بۆ بێت، بزانن دەبێت چەند پارە بدەن.
- **ئاگادارکردنەوەی ژیرانە:** بزانن کەی کارەباکە دەچێتە سەر ئاستە گرانەکان بۆ ئەوەی دەستپێوەگرتن بکەن.

## 🚀 تایبەتمەندییەکان
- **دیزاینی مۆدێرن:** گونجاوە بۆ هەموو جۆرە مۆبایل و تابلێتێک.
- **تەکنەلۆژیای سووک:** بەبێ سێرڤەر و بە خێراییەکی زۆر کار دەکات (HTML/CSS/JS).
- **بە زمانی کوردی:** ڕووکارێکی سادە و تێگەیشتوو بۆ هەموو تەمەنەکان.

## 🛠 چۆن بەکاری بهێنم؟
١. بڕی ئەو یەکانەی (kWh) کە لەسەر پێوەرەکە نوسراوە داخڵ بکە.
٢. بودجەی مانگانەی خۆت دیاری بکە (بۆ نموونە: ٥٠,٠٠٠ دینار).
٣. دوگمەی "هەژمارکردن" دابگرە تاوەکو وردەکارییەکان و ئامۆژگارییەکان ببینی.

## 🤝 بەژداریکردن (Contribution)
ئەم پڕۆژەیە بۆ خەڵکە و لەلایەن خەڵکەوە گەشەی پێ دەدرێت. ئەگەر گەشەپێدەریت (Developer) و دەتەوێت تایبەتمەندی نوێ زیاد بکەیت یان نرخەکان نوێ بکەیتەوە، دەتوانیت "Pull Request" بنێریت.
